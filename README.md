# Ciber Sherlocks · CyberSec Tech Day

Experiencia gamificada (móvil) para explorar Cisco Secure Workload como detectives forenses.
Sin backend: todo corre en el navegador; el progreso se guarda en el teléfono de cada participante.

## Contenido
- `index.html` — la app completa en un solo archivo (fuentes y código incluidos).
- Las fotos se cargan desde el CDN de Gamma (requiere internet).

## Publicar en GitHub Pages
1. Crea un repo nuevo, p. ej. `doja-sec/ciber-sherlocks` (público, o privado con plan que permita Pages).
2. Sube `index.html` y este `README.md` a la raíz de la rama `main`.
3. Settings → Pages → Source: *Deploy from a branch* → `main` / `(root)` → Save.
4. En 1–2 min queda en `https://doja-sec.github.io/ciber-sherlocks/`.
5. Genera un QR con esa URL para el stand.

## Uso en el evento
- En celulares se abre a pantalla completa; en computador se ve dentro de un marco de teléfono.
- PIN del facilitador: **2026**.
- "Reiniciar juego" (en el tablón) o "Nuevo equipo" (en el expediente final) borra el progreso del teléfono.
